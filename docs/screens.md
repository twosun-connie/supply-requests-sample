# 화면 목록

| 화면 | 경로 | 누가(권한 코드) | 보이는 것 | 할 수 있는 것 | 시안 |
|---|---|---|---|---|---|
| 사용자 관리 | `/admin/users` | `users.manage` | 사용자 이름, 가입일, 역할 | 역할 바꾸기 | 없음 |
| 신청 목록 | `/requests` | 로그인한 모든 사용자 | 자기 신청. `requests.approve` 가 있으면 전체 신청과 신청자 이름. 열: 품목, 수량, 상태, 신청일 | 상태로 거르기, 쪽 이동, 「새 신청」, 상세 열기 | 없음 |
| 새 신청 | `/requests/new` | 로그인한 모든 사용자 | 품목(쓰는 품목만), 수량, 사유, 희망 지급일 | 제출. 제출하면 신청 목록으로 간다 | 없음 |
| 신청 상세 | `/requests/[id]` | 신청자 본인 또는 `requests.approve` | 신청 내용, 상태, 담당자 메모, 이력(언제 누가 어떤 상태로) | `requests.approve`: 승인, 반려(사유 입력). 제출 상태일 때만 버튼이 보인다 | 없음 |

## 화면별 메모

### 신청 목록
- 빈 상태의 문구: "아직 신청이 없습니다. 「새 신청」을 눌러 시작하세요."
- 정렬: 신청일 최신순. 20행씩.
- 상태 필터는 주소의 `?status=` 에 둔다. 값이 없으면 전체.

### 새 신청
- 쓰는 품목이 하나도 없으면 폼 대신 "신청할 수 있는 품목이 없습니다. 관리자에게 문의해 주세요."를 보여 준다.

### 신청 상세
- 볼 수 없는 신청이거나 없는 신청이면 404.
- 자기 신청에는 승인·반려 버튼이 보이지 않는다.
