- 상태: 완료
- 요청: 소규모 도구용 템플릿에 작업시 네이밍 컨벤션, 주석(코드주석, DB 스키마 주석 등등)이 명확하게 모두 작성될 수 있도록 적용해줘. 그리고 git commit, pr 메시지도 현업에서 많이 사용하고 잘 관리되는 형식으로 작성될 수 있도록 적용해줘.
- 근거 문서: docs/schema.md, .claude/rules/conventions.md, .claude/rules/git.md

## 계획

- 쓰는 테이블과 권한 코드: 없음
- 마이그레이션: comment_schema(설명만 단다. 데이터와 구조는 그대로. 정책 이름 1건)
- 하지 않을 것: 열·테이블·인덱스 이름 바꾸기(지금 이름은 모두 규칙에 맞는다)

## 결정

| 정한 것 | 고른 것 | 다른 선택지 | 이유 | 정한 사람 |
|---|---|---|---|---|
| 커밋 형식 | Conventional Commits 1.0.0 | gitmoji, 자유 형식 | 가장 널리 쓰이고 종류로 변경 기록을 가를 수 있다 | AI(사용자 확인 전) |
| 형식 검사 | 직접 쓴 Node 스크립트 | commitlint(패키지 4개) | 규칙이 적다. 새 패키지를 늘리지 않는다 | AI(사용자 확인 전) |
| DB 설명의 범위 | 모든 열(id, created_at 포함) | 뜻이 분명한 열은 생략 | 「어느 열은 빼도 되는가」를 판단하게 두면 빠진다 | AI(사용자 확인 전) |
